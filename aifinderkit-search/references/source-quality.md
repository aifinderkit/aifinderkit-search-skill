# Source Quality

Rank evidence in this order when it is applicable:

1. Official specifications, documentation, repositories, filings, datasets, and first-party announcements.
2. Peer-reviewed papers or identifiable institutional research.
3. Reputable reporting with named evidence and a clear publication date.
4. Independent technical analysis that exposes methods or reproducible artifacts.
5. Forums, social posts, snippets, and unattributed summaries only as discovery leads.

Check that the page actually supports the nearby claim, the publication date matches the requested time range, and two apparently different pages are not copies of the same upstream story. Treat a multi-source retrieval match as stronger discovery evidence, but verify consequential claims in fetched content. If only weak sources are available, say so.
